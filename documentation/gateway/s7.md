## Raw S7 Protocol

The gateway exposes the S7 (ISO-on-TCP) server interface directly via the Snap7 library, accepting PUT/GET requests from Siemens PLCs and S7-compatible devices.

### S7 Server

The gateway runs an S7 server on **TCP port 102** (ISO-on-TCP). Siemens PLCs configured to send data via PUT/GET connect to this port as the communication partner.

### PLC Configuration

In the TIA Portal project, configure the partner endpoint on the PLC side:

| Parameter | Value |
|-----------|-------|
| Partner IP | Gateway IP |
| Partner Port | 102 |
| Transport Protocol | ISO-on-TCP |
| Local TSAP | 0x0200 |
| Remote TSAP | 0x0200 |

### Supported Data Types

All S7 primitive types are supported:

| S7 Type | C++ Type | Description |
|---------|----------|-------------|
| `BOOL` | `bool` | Single bit |
| `BYTE` | `uint8_t` | 8-bit unsigned |
| `WORD` | `uint16_t` | 16-bit unsigned |
| `DWORD` | `uint32_t` | 32-bit unsigned |
| `INT` | `int16_t` | 16-bit signed |
| `DINT` | `int32_t` | 32-bit signed |
| `REAL` | `float` | 32-bit IEEE 754 |
| `LREAL` | `double` | 64-bit IEEE 754 |
| `TIME` | `uint32_t` | Milliseconds |
| `STRUCT` | (composite) | UDT instances |
| `ARRAY` | (composite) | Fixed-length arrays |

### Byte Order

S7 uses **big-endian** byte order. The gateway transparently converts to host byte order for northbound clients. Raw binary endpoints (`/memory/db/...`) return raw big-endian bytes for clients that need to cast directly.
