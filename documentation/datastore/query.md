# Query API

These endpoints are convenience “lookup” endpoints used by the web UI.

## List Organisations

`GET /api/v1/query/organisations`

Public endpoint returning `{id, name}` pairs.

## List Departments

`GET /api/v1/query/departments`

Public endpoint returning `{id, name}` pairs.

## List Statuses

`GET /api/v1/query/statuses`

Public endpoint returning `{id, name}` pairs.

## User Info

`GET /api/v1/query/user/info`

Returns detailed information about a user.
